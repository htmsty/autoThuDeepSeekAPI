## 一、本轮要修 / 要加的东西

### 1. 修"上一次同步还没结束"卡死，并加「强行终止并重试」

- **Bug**：第一次运行时点 `X` 关掉内置浏览器窗口后，程序没清掉"正在取 Token"的状态，
  之后每次点同步都被"上一次同步还没结束，忽略这次请求"挡掉，只能重启程序。
- **修法**：浏览器窗口被用户关掉（`X`）时按"取消"处理，立即清掉进行中的取 Token 状态。
- **新增**：用户点同步时如果确实还在忙，弹确认框，按钮为「强行终止并重试」/「取消」。
  确认后终止当前的取 Token 或同步，然后重新开始这一次同步。
- **安全优先**：终止 = "在步骤之间安全停下"，绝不杀线程。正在写的那一份文件先原子写完
  （失败有回滚兜底），下一个步骤开始前才停。

### 2. 设置里加「恢复默认设置」

- 一键把设置项恢复成程序默认值（自动同步开、间隔 180 分钟、统一 profile 勾选、预检开等），
  保存并立即刷新主界面与设置界面。
- 开机启动项（注册表）**不动**，避免"恢复默认"顺手改系统状态。
- 与第 3 条联动：同时询问是否把 private 数据文件夹位置也还原为默认。

### 3. 程序在桌面根目录时提醒 + private 位置可选

- **判定**：只认 exe 直接在**桌面根目录**；桌面下的子文件夹不算。
- **前提**：private 还没被挪走。如果 private 已经指向别处，桌面不会生成 private，不再提醒。
- **弹窗**：说明"继续运行会在桌面生成/使用 `private` 数据文件夹（不要删，删了会丢 Token、
  备份和设置）"，三个按钮：
  - 「选择 private 位置…」→ 选好并搬迁后不再提醒；
  - 「仍然继续」→ 写状态，以后不再提醒；
  - 「退出程序去换位置」→ 直接退出，**不写状态**（下次仍会提醒）。
- **private 位置设置项**：设置里新增一行显示当前位置，可「更改位置…」。
  - 校验并避开不安全 / 要权限 / 易报毒的位置：系统目录（Windows、System32）、
    Program Files、ProgramData、盘符根、临时目录、桌面；并要求目录可写。
  - 换位置时把现有 private 内容搬过去（同盘优先改名、跨盘复制），重启后生效。
- **指针文件**：选择的 private 位置记在 `%LOCALAPPDATA%\autoThuDeepSeekAPI\private-location.json`。
  理由：不能放在 private 自己里面（换了位置就找不回来），也尽量不在桌面留文件；
  「干净卸载」会把它一起删掉。

### 4. 自动同步默认 180 分钟

- 新装默认：自动同步开、间隔 180 分钟。
- 老设置一次性迁移；**用户自己填过的间隔保留**，不被默认值覆盖。
- 回归用例覆盖默认值与迁移。

### 5. 干净卸载（设置里，二次确认）

- **不删程序自己**。只清程序管理的东西：设置、状态、日志、备份、浏览器会话、模型缓存、
  提醒状态、锁文件、private 位置指针。
- 自选 private 目录里属于用户自己的文件一律不动，**不整个删目录**（删完只剩空目录就留着）。
- 执行前询问"是否把 DSH / CC Switch 还原到第一次备份"，并**提示风险**：
  会覆盖这两个应用当前的配置，可能影响正在使用的模型与令牌。
- 完成后提示"请手动删除程序自身的 exe"，并自动退出。
- 实现只用正常的文件操作，不写自删除脚本、不调用 `rd` / `del` / `reg`，避免触发报毒。

### 6. DSH 与 CC Switch 都没检出时的提醒

- 启动时若两边**真的都没有任何痕迹**，弹警告并跳过这一次同步（不再傻等、不再报一堆错）。
- 文案（用户给定）：

  > 未检测到 DSH / CC Switch 的配置：如果已安装，请先分别运行一次让它们生成配置然后退出，
  > 或在上方指定路径，

- **只弹一次**：用户点过「知道了」就写状态，以后不再弹（仍然安静地跳过无意义的同步）。
- "没有任何痕迹"的判据：配置文件/目录不存在、自定义路径不存在、进程没在跑、
  常见安装目录也没有 —— 任一命中就算"有痕迹"，不弹。

### 7. 第 3 条与第 6 条同时成立时的顺序

- 先弹第 3 条（程序在桌面），处理完再弹第 6 条（都没安装）。
- 两条都处理过之后，状态写入 `private/`，都不再重复提醒。

## 二、实现约束

- 隐私与运行数据只写在 private（默认程序目录旁，可改位置）；仓库里不出现 Token、账号、本机路径。
- 所有写入目标先备份、再写、再校验；失败保留现场并说明原因。
- 「强行终止」永远是安全停止，不调用 `QThread.terminate()`。
- 卸载与搬迁只用 Python 标准库的文件操作，不生成脚本、不碰注册表。
