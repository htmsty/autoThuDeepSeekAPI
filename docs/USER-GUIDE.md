# 使用手册

这份手册面向**使用者**：安装、第一次登录、每个按钮和每个设置项的作用、常见问题、卸载。
开发与实现细节见 [README.md](../README.md) 与 [ARCHITECTURE.md](../ARCHITECTURE.md)。

- 程序名：Auto THU DeepSeek API
- 作者：htmsty
- 项目主页：<https://github.com/htmsty/autoThuDeepSeekAPI>

---

## 1. 它是什么

一个 Windows 便携程序：

1. 用**程序内置的浏览器窗口**打开清华大学 MadModel 平台的统一身份认证，你自己登录；
2. 登录成功后程序自动捕获 Token、关掉窗口、校验 Token 是否可用；
3. 把 Token 写进你启用的目标：

   - **DeepSeek Harness（DSH）**：`.dsh\.credentials.yaml` 里的 `MADMODEL_API_KEY`，
     以及各 profile 的 `cordis.patch.yml` 里的 `madmodel` provider；
   - **CC Switch**：供应商卡片 `DeepSeek (THU)` 与"当前供应商"路由。

4. 之后可以按你设置的间隔自动同步；每次写入前自动备份，随时能一键还原。

程序**不会**模拟点击、不会替你输密码，也不把任何数据上传到别处。

## 2. 安装与启动

### 2.1 该用哪个版本

发行包里有两个形态，功能完全一样：

| 形态 | 说明 | 建议 |
| --- | --- | --- |
| 文件夹版（`autoThuDeepSeekAPI\` 目录） | 启动快、体积展开 | **日常使用推荐** |
| 单文件版（`autoThuDeepSeekAPI.exe`） | 只有一个文件，启动时要先解包（慢几秒） | 偶尔换机器时方便 |

把选好的版本放到一个固定目录（例如 `D:\Tools\autoThuDeepSeekAPI\`），双击运行即可，
不需要安装。也可以右键「发送到 → 桌面快捷方式」，或者用程序里的
「创建桌面快捷方式」按钮生成一个。

### 2.2 关于"程序放在桌面上"的提醒

如果你把程序**直接放在桌面根目录**（桌面里的子文件夹不算），第一次启动会提醒一次：
继续运行会在桌面生成 `private` 数据文件夹，里面是 Token、设置、备份和浏览器会话。

这时你可以：

| 选择 | 结果 |
| --- | --- |
| 选择 private 位置… | 把运行数据放到别处（推荐，例如 `D:\autoThuDeepSeekAPI-data`），以后不再提醒 |
| 仍然继续 | 保持现状，以后不再提醒 |
| 退出程序去换本程序位置 | 直接退出（不记"已处理"）；把程序挪到别处再运行即可 |

按 `ESC` 或点右上角 `×` 关掉这个提醒，**不算**做过选择：这一次启动会继续运行，
下次启动仍会提醒（同一次启动里不会重复弹）。

### 2.3 第一次同步

1. 打开程序，点主界面的「**立即获取并同步**」；
2. 在弹出的**内置浏览器窗口**里完成清华统一身份认证；
3. 程序检测到 Token 后会自动关闭窗口，校验并写入你启用的目标；
4. 主界面状态栏、Token 状态、日志区都会显示结果，右下角（系统托盘）也会弹一条通知。

如果 DSH 与 CC Switch 都还没用过（配置目录都不存在），程序会先提醒你去装并各运行一次，
这一次同步会跳过。

## 3. 主界面

### 3.1 状态区

| 显示 | 含义 |
| --- | --- |
| DeepSeek Harness | 是否检测到 DSH 配置目录（以及有几个 profile） |
| CC Switch | 是否检测到 CC Switch 数据库 |
| Token | 当前 Token 的到期时刻（"有效至 …"）或"已过期／尚未获取" |
| 上次同步 | 最近一次同步的时间与结果摘要 |

底部状态栏显示运行数据目录，右下角「程序日志」实时显示日志。

### 3.2 按钮

| 按钮 | 做什么 |
| --- | --- |
| 立即获取并同步 | 打开内置浏览器（已经登录过就直接静默取），拿到 Token 后校验并写入 |
| 校验写入内容 | **只读**检查：把"将要写入的内容"渲染出来逐项校验，不改任何文件 |
| 手动备份 | 立刻给 DSH 凭据、各 profile、CC Switch 数据库与路由文件各留一份备份 |
| 一键还原 | 把各文件恢复成最早的备份（= 本程序第一次改它之前的样子）；还原前会先把当前状态备份一份 |
| 设置… | 打开设置对话框（下面第 4 节） |
| 创建桌面快捷方式 | 在桌面生成一个指向本程序的快捷方式 |
| 打开日志 | 打开日志目录 |
| 打开数据目录 | 打开 `private` 运行数据目录 |
| 关于… | 显示版本号、作者、项目主页与数据目录（报障时先看这里） |
| 退出 | 真正退出程序（点窗口 `×` 默认只是最小化到托盘） |

### 3.3 开关与间隔

| 控件 | 说明 |
| --- | --- |
| 开机启动（最小化到托盘） | 写进当前用户的注册表启动项；程序被移动位置后会在下次启动时自动纠正路径 |
| 启动时立即同步 | 每次启动后自动跑一次同步（默认开） |
| 自动同步 | 按下面的间隔在后台自动同步（默认开） |
| 间隔（分钟） | 1–1440 分钟，默认 180；旁边有 20 / 60 / 180 分的快捷按钮 |
| 同步完成立即最小化到托盘 | 勾上后每次同步完成窗口自动隐藏 |

所有开关改动都会立即保存，不需要"确定"。

### 3.4 托盘

- 点窗口 `×` 默认最小化到系统托盘（可在设置里改成直接退出）；
- 托盘图标**左键单击或双击**打开主界面，**右键**弹出菜单：
  打开主界面 / 立即获取并同步 / 打开日志 / 设置 / 关于 / 退出；
- 同步成功或失败都会弹一条气泡通知。

## 4. 设置对话框

### 4.1 写入目标

| 设置项 | 说明 |
| --- | --- |
| 启用 DSH 写入（凭据 + provider） | 关掉就完全不碰 DSH 的文件 |
| DSH 目录 | 留空 = 自动用 `%USERPROFILE%\.dsh`；也可以手动指定 |
| 统一所有 profile 到 madmodel | **勾选（默认）**：所有 profile 都写入，并把每个 profile 的默认模型指向 `madmodel`；**不勾**：只更新"已经配置过 madmodel"的 profile，默认模型保持你在 DSH 里选的那个 |
| 启用 CC Switch 写入 | 关掉就完全不碰 CC Switch |
| CC Switch 目录 | 留空 = 自动用 `%USERPROFILE%\.cc-switch` |
| 顺带刷新同站点旧卡片的令牌 | **默认关**。打开后，配置里出现清华站点的**其它**卡片，其 Token 字段也会被换成新 Token（只换 Token，不动别的字段） |

### 4.2 CC Switch 正在运行时

两个选项，二选一：

| 选项 | 行为 |
| --- | --- |
| 先提示我，由我决定 | 同步前检测到 CC Switch 在运行就问一次，你可以选「关闭好了，继续」「直接改」或「取消」 |
| 不提示，直接改数据库（默认） | 不弹提醒直接写；更快，但 CC Switch 之后可能用内存里的旧数据覆盖掉这次修改 |

在提示框里勾「以后不再提示（以后都直接改）」并确认，等于把策略切成"直接改"；
如果点的是「取消」，勾选不会生效。

### 4.3 备份与还原

- **备份保留份数**：每个文件保留几份普通备份（默认 10）。第一次运行留下的"原始备份"
  永远保留，不占这个额度。
- **还原到首次修改前**：和主界面「一键还原」同一件事；还原前会把当前状态再备份一份，
  所以还原本身也能退回来。
- **手动粘贴 Token…**：内置浏览器不好用时的兜底。把站点「API 使用指南 → 复制 token」
  的内容粘进来，确定后会用它同步；粘贴的内容必须是 JWT（程序会检查格式）。

### 4.4 运行数据与维护

| 按钮 | 说明 |
| --- | --- |
| 更改位置… | 把 `private` 运行数据搬到别的文件夹。会拒绝系统目录、Program Files、ProgramData、盘符根、临时目录、桌面；搬完重启生效 |
| 恢复默认设置 | 把所有设置恢复成默认值（开机启动项与"上次同步"记录不动）；如果 private 位置被改过，会再问你要不要一起还原 |
| 干净卸载… | 见下面第 7 节 |

### 4.5 更多

| 设置项 | 说明 |
| --- | --- |
| 同步前先预检 | 默认开。关掉就跳过预检直接写（不建议） |
| 点 × 时最小化到托盘 | 默认开；取消勾选则点 `×` 直接退出 |
| 静默取 Token 超时 | 自动同步时后台等 Token 的上限（10–600 秒，默认 40）。超时会提示"多半需要重新登录"，并沿用仍在有效期内的旧 Token |
| DSH 默认模型 | 勾了"统一所有 profile"时写进 `agent-default-model` 的模型 id；留空/默认 = 用站点清单里的第一个 |
| 日志级别 | INFO / DEBUG（保存后立即生效；排查问题时再开 DEBUG） |
| 创建桌面快捷方式 | 与主界面按钮相同 |

## 5. 备份与还原

- 程序**第一次运行**时，会先把 DSH 凭据、各 profile、CC Switch 数据库与两个路由文件
  各备份一份（带 `original` 标记，永不清理）；
- 之后每次真正要写文件之前，都会再留一份普通备份（按"备份保留份数"轮换）；
- 备份放在 `private\backups\` 下，每个快照目录里都有 `source.txt` 记录它来自哪个文件，
  方便人工翻看；
- 「一键还原」= 把每个文件恢复到**最早**那一份备份（也就是本程序第一次改它之前）；
- 清理旧备份走**回收站**，可以撤销。

## 6. 数据、隐私与安全

### 6.1 数据都在哪

默认在程序目录下的 `private\`：

```
private/
  settings.json       你的设置
  state.json          运行状态（最近 Token、时间戳）
  model-cache.json    站点模型清单缓存（6 小时）
  logs/               日志（按天 + 按大小轮转）
  backups/            备份与还原索引
  browser-profile/    内置浏览器独立档案（保存登录会话）
```

程序目录不可写时自动改用 `%LOCALAPPDATA%\autoThuDeepSeekAPI\private\`。
你把 private 位置改到别处后，位置记在 `%LOCALAPPDATA%\autoThuDeepSeekAPI\private-location.json`。

### 6.2 隐私

- Token、日志、备份、浏览器会话**只保存在本机**，程序不把它们上传到任何服务器；
- 程序访问网络只有这几件事：打开清华 MadModel 站点登录页；读取站点前端包里的模型清单
  （读不到时退回站点的 `/v1/models`，再读不到就用内置名单）；向站点校验 Token 是否可用。
  日志里只记 Token 的**指纹**（16 位十六进制），不记完整 Token。

### 6.3 会不会改动我的其它配置

程序只写下面这些位置，别的文件一律不碰：

| 文件 | 只写什么 |
| --- | --- |
| `.dsh\.credentials.yaml` | `MADMODEL_API_KEY` **这一行**（保留其它 key、注释与引号风格） |
| `.dsh\profiles\*\cordis.patch.yml` | 我们自己的 `madmodel` provider 块与（真要改时的）`agent-default-model` 条目；别人的 provider、其它条目、注释、缩进一个字节都不动 |
| `.cc-switch\cc-switch.db` | 卡片 `(deepseek-thu, codex)` 一行；「当前供应商」语义要求把同应用下其它卡片的 `is_current` 置 0 |
| `.cc-switch\settings.json` | `currentProviderCodex` 这一行（缺这个键时只在对象末尾补一行） |
| `.cc-switch\live-state.json` | `apps.codex.proxy_route` 这一行（缺 `apps.codex` 时只补出缺的部分） |
| `private\**` | 程序自己的设置 / 状态 / 日志 / 备份 / 浏览器会话 / 模型缓存 |

如果某个 profile 用了程序认不出来的写法（例如 provider 写成一行内联 map）而旁边又有别人的
provider，程序会**报错并跳过写入**，而不是整份重写去冒改坏别人配置的风险。

## 7. 卸载

设置 →「运行数据与维护 → 干净卸载…」，需要连续确认两次，并单独问你：

> 要不要把 DSH / CC Switch 还原到本程序第一次修改之前的备份？

- 选「是」：先还原（会覆盖这两个应用当前的配置，**有风险**，界面上有提示），再清运行数据；
- 选「否」：只清程序自己的运行数据。

然后程序会：

1. 删掉 `private` 里属于程序自己的条目（Token、设置、状态、日志、备份、浏览器会话、模型缓存、
   提醒状态、单实例锁）；
2. 删掉位置指针文件；
3. **不会**删除程序自己的 exe（对话框里会告诉你具体路径，手动删即可）；
4. 你放在 private 目录里的其它文件不会被删；目录本身也保留（不整个删目录）；
5. 所有删除都先走**回收站**，可以撤销；
6. 退出程序（之后不会再把设置写回磁盘）。

卸载流程只用普通文件操作，不写自删除脚本、不调用 `rd` / `del` / `reg`，不会被当成恶意行为。

## 8. 常见问题

**Q：点「立即获取并同步」后窗口一闪而过／要求登录？**

第一次运行时浏览器档案里还没有登录会话，程序会直接打开登录窗口。
完成一次登录后，会话会保存在 `private\browser-profile\`，之后就可以静默取 Token。

**Q：自动同步提示"静默取 Token 超时：多半需要重新登录"？**

说明站点会话过期了。点一次「立即获取并同步」手动登录即可；
如果你还有未过期的旧 Token，程序会沿用它继续同步。

**Q：提示"程序已经在运行"？**

同一份程序只允许开一个实例。请到系统托盘找它；如果托盘里没有，等几秒再试
（刚重启完时旧进程可能还没退干净）。如果提示是"无法在运行数据目录建立锁文件"，
按提示检查那个目录是否可写。

**Q：提示"没有检测到 DSH / CC Switch"？**

两个程序的配置目录都不存在时会出现。请先分别安装并运行一次 DSH / CC Switch，
让它们生成配置后再同步；已经装好但目录在别处时，可以在设置里手动指定目录。

**Q：提示"没有启用任何写入目标"？**

设置里 DSH 写入与 CC Switch 写入都被关掉了，至少打开一个。

**Q：提示"上一次同步还没结束"？**

点「强行终止并重试」即可：程序会在**安全的位置**停下（正在写的那一份文件先写完），
然后自动重新开始；点「取消」则什么都不做。

**Q：DSH 报 `provider "…" model "…" does not support reasoning effort "…"`？**

这是 DSH 的思考档位与模型不匹配。程序在每次同步时会把 provider 的默认思考档修正成
所有模型都支持的公共档位，并且只在"用户设的档位确实不合法"时才改，不会动你合法设置。
同步一次后重启 DSH 即可。

**Q：DSH 报"模型不存在"？**

站点的模型清单会变（改名、下架）。程序每次都从站点前端包读取当前清单并同步到 provider，
所以同步一次通常就能修好。手动往 provider 里加的模型会被站点清单覆盖，需要长期保留请提 issue。

**Q：同步日志显示"无变化"是不是没同步？**

是已经是最新状态，程序没有重复写文件（不写 = 不改动你的配置，这是有意设计）。
Token 是否有效可以看主界面 Token 状态与日志里的校验结论。

**Q：CC Switch 正在运行，会不会写坏？**

默认策略是"不提示、直接改"，快速但不保证 CC Switch 不覆盖。稳妥做法是在设置里改成
「先提示我，由我决定」，同步前先退出 CC Switch。

**Q：杀毒软件报毒？**

程序是 PyInstaller 打包的 Python 程序，部分杀软会误报。可以：
把整个程序目录加入白名单；或从源码运行（见 README）；或核对发行版的 SHA256
（`releases/<版本>/SHA256.txt`）。

**Q：想把开机启动关掉？**

主界面把「开机启动（最小化到托盘）」取消勾选即可（它写的是当前用户注册表启动项，
不勾就会删掉）。用第三方工具删过启动项也没关系：程序下次启动会读到"未启用"并同步界面状态。

**Q：程序在哪、配置文件在哪？**

主界面「关于…」里能看到版本、作者、项目主页和数据目录；
「打开数据目录」按钮直接打开运行数据目录。

**Q：怎么反馈问题？**

在「关于…」里记下版本号；把「打开日志」里的日志文件（`private\logs\app-YYYYMMDD.log`）附上，
到项目主页开 issue：<https://github.com/htmsty/autoThuDeepSeekAPI/issues>。
日志里不会出现完整 Token。

## 9. 版本与更新

- 当前版本号显示在主界面「关于…」里；源码里对应 `constants.APP_VERSION`；
- 每个版本的改动见 [CHANGELOG.md](../CHANGELOG.md)；
- 发行版的单文件程序留档在仓库外的 `releases/<版本>/`，仓库里只记录 SHA256
  （单文件程序超过 GitHub 的单文件上限，不进 Git）。
